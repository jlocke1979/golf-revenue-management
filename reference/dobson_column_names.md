# Column names in the City of Mesa Dobson Ranch export

Column names in the City of Mesa Dobson Ranch export

## Usage

``` r
dobson_column_names()
```

## Value

A character vector of the 23 catalog field names, in catalog order.

## Examples

``` r
dobson_column_names()
#>  [1] "RowID"               "Date"                "Calendar Year"      
#>  [4] "Fiscal Year"         "Month"               "Day"                
#>  [7] "Day of Week"         "Sunrise"             "Sunset"             
#> [10] "Cart Rentals"        "Cart Revenue"        "Club Rentals"       
#> [13] "Club Revenue"        "Food and Beverage"   "Green Fees"         
#> [16] "Merchandise Revenue" "Range Sales"         "Rounds Possible"    
#> [19] "Round Booking Rate"  "Rounds Played"       "Total Revenue"      
#> [22] "Revenue/Round"       "Season"             
```
