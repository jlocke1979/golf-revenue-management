# RevPATR by year

One line for total revenue and one line for green fees. Each point is
that year's revenue divided by the daylight estimate of rounds. See
[`revenue_per_available_round()`](https://jlocke1979.github.io/golf-revenue-management/reference/revenue_per_available_round.md).

## Usage

``` r
plot_revpatr(data)
```

## Arguments

- data:

  Daily rows from
  [`dobson_operating_daily()`](https://jlocke1979.github.io/golf-revenue-management/reference/dobson_operating_daily.md).

## Value

A ggplot object.
